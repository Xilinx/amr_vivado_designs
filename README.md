# emb_plus_vivado_designs


## Introduction
This repo is used to capture Vivado XSA generation of the Embedded+ HW/PL platform
The emb_plus_ve2302 hw_platform targets the ve2302 FPGA.

## Instructions

This repo contains submodules. To clone this repo, run:
```
git clone --recursive https://github.com/Xilinx/emb_plus_vivado_designs.git
```

## Contents

This repo contains Vivado platforms.

Platforms list:
- ve2302_1gEth
